# 🛡️ Network Intrusion Detection System (NIDS)

This project was completed as **Task 4** for the **CodeAlpha Cyber Security Internship**.

## 📌 Project Overview

This project implements a **Python-based Network Intrusion Detection System (NIDS)** that monitors live network traffic, analyzes packets, and generates alerts for suspicious network activities.

---

## 🎯 Objectives

- Monitor live network traffic
- Detect suspicious packets
- Generate real-time alerts
- Log security events
- Demonstrate intrusion detection concepts

---

## 🛠️ Technologies Used

- Python 3
- Scapy
- Visual Studio Code
- Git & GitHub
